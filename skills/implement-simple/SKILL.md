Before beginning, `/update-working-copy`

Implement the work described by the user in the spec or tickets.

Use `/verify` to verify code as it is written.

Once done, use `/review-and-wrapup` to review and complete your work with one modification:
if a `reviewer-simple` agent is available, use that in place of a `reviewer` agent.
